# Betting — футбольные прогнозы

Статический сайт с автоматическим сбором данных. Используются **GitHub Actions + GitHub Pages**, Vercel не нужен.

## Как работает

1. GitHub Actions запускается раз в 3 часа, после изменения кода или вручную.
2. Node.js-скрипт получает данные BSD, SStats, Euro365 и football-data.org.
3. Скрипт собирает единый `data.json`. Токены используются только в Actions и не передаются браузеру.
4. Actions сохраняет `data.json` в репозитории. GitHub Pages автоматически публикует обновлённый сайт.
5. Кнопка «Обновить» перечитывает последнюю опубликованную копию данных. Она не запускает API-запросы из браузера.

Сайт: https://he-sytikova.github.io/betting/

## Настройка репозитория

### 1. Добавьте API-секреты

Откройте **Settings → Secrets and variables → Actions → New repository secret**. Добавьте ключи, к которым у вас есть доступ:

- `BSD_TOKEN` — Bzzoiro Sports Data.
- `SSTATS_TOKEN` — SStats.net.
- `EURO365_API_KEY` — Euro365 (необязательно).
- `FD_DATA_TOKEN` — football-data.org (необязательно).

Достаточно настроить хотя бы один источник. Отсутствующий ключ не раскрывается в коде сайта; источник будет отмечен как недоступный.

### 2. Включите GitHub Pages

Откройте **Settings → Pages** и выберите:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

Это использует уже настроенную публикацию GitHub Pages из корня ветки `main`.

### 3. Запустите обновление

Откройте **Actions → Update and publish football forecasts → Run workflow**. Дождитесь завершения задачи. Если API-секреты корректны, в репозитории появится или обновится `data.json`, после чего Pages опубликует новую версию сайта.

## Данные и вероятности

Таблица показывает доступные прогнозы по исходам, тоталам голов, xG, угловым и жёлтым карточкам — в зависимости от полей, которые возвращает поставщик. Если источник не предоставляет конкретный рынок или вероятность, отображается тире. Для football-data.org часть вероятностей рассчитывается моделью Пуассона по недавним результатам и является модельной оценкой, а не гарантией результата.

Формат API может отличаться в зависимости от доступа и версии поставщика. Если матчей нет, откройте журнал последнего запуска в **Actions** и наведите курсор на статус источника на сайте, чтобы увидеть диагностическое сообщение.
