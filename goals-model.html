Угловые и жёлтые карточки → Экспериментальная модель угловых и ЖК v1 Главная страница
Экспериментальная исследовательская версия. Вероятности рассчитываются самостоятельно по историческим данным. Красные карточки и рынок точного счёта исключены. Матрица счёта используется только внутри для суммирования вероятностей других рынков.

Нет предстоящих матчей, для которых сопоставлены лига и обе команды с историческими данными.

Модель не является рекомендацией для ставок. Метрики MAE/Poisson deviance оценивают прогноз числа голов и не заменяют проверку Brier Score, Log Loss и калибровки вероятностей рынков.
